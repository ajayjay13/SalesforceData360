Things that are easy to mix up

  • HarmonizationorUnification

    Harmonization maps data into the common model. Unification (identity resolution) links records into one profile. Harmonize first.

  • Data streamorData lake object

    A stream is the pipe and its configuration. The DLO is where the data is stored.

  • DLOorDMO

    DLO holds data. A mapped DMO is a view that points at it.

  • IngestionorMapping

    Two separate steps. Landing data in a DLO does not map it.

  • FormulaorData transform

    Formula: light fixes at ingestion only. Transform: joins, aggregates, splits, on data already in.

  • Batch transformorStreaming transform

    Batch: full refresh, DLO or DMO source. Streaming: row by row, DLO only.

  • Unified IndividualorGolden record

    Unified Individual links source records. Nothing is merged or deleted.

  • Match rulesorReconciliation rules

    Match: same person? Reconciliation: which value wins?

  • Calculated InsightorStreaming Insight

    Batch metrics over the full model vs minute-level windows over streamed data.

  • Streaming InsightorReal-Time Insight

    Minutes vs milliseconds. Streaming feeds data actions. Real-time feeds personalization.

  • SegmentorActivation

    Who vs where. Output is IDs vs a JSON payload to a target.

  • ActivationorData action

    Batch segment publishing vs event-driven triggers.

  • Standard data actionorReal-Time data action

    Within minutes to Platform Events, MCE, webhooks vs about 300 ms through a data graph.

  • Related List enrichmentorCopy Field enrichment

    Many records on a page vs one value onto a field.

  • ShouldForgetorProcessing

    Delete the person's data vs stop using it but keep it.

  • Permission setorProfile

    Permission sets give Data 360 capabilities. The Identity User profile gets people in. Neither gives CRM reporting.

  • Data spaceorData residency

    A data space separates data logically. It does not control where data is hosted.

  • Vector searchorHybrid search

    Meaning only vs meaning plus exact keywords.

  • RetrieverorEnsemble retriever

    One index vs a combined, reranked set of retrievers.

  • EnabledorImplemented

    Agentforce needs Data 360 enabled. Customer 360 data, cleansing and custom RAG need it implemented.

  • Trust LayerorGovernance and consent

    Trust Layer protects AI calls. It does not replace consent or governance.

  • Standard reportorCustom report

    One DMO, CIO or semantic model vs up to 4 related DMOs.
