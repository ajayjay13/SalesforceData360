Data Source Connection and Ingestion

Connectors, data streams, data categories, formulas, transforms, keys and Zero Copy. Getting data in, in the right shape.

  • Explain data transformation capabilities within Data 360.
  • Describe processes and considerations for data ingestion from varied sources into Data 360.
  • Describe Data 360's data collaboration capabilities, including Zero-Copy.

Path of one data stream

  1. SourceCRM, MCE, S3, SDK, API
  2. Data streampipe, schedule, category
  3. DLOstored data, minor formula fixes
  4. Transformbigger reshaping, optional
  5. MapDLO fields to DMO fields
  6. DMOview over mapped DLOs

A mapped DMO does not copy data. It points at the DLO. Ingestion and mapping are separate steps.

Three data categories

Profile

  • Segment-oriented. Any population you want to segment by
  • Account, contact, subscriber, loyalty member, customer

Engagement

  • Time-series. Needs an Event Time field
  • Pick an immutable date or records duplicate
  • Email sends, sales orders, web events, cases

Other

  • Related to profile or engagement
  • Time-series without an immutable date
  • Prices, products, contact points, consent, benefits

Formulas versus transforms

Formula fields

  • Applied only when data is ingested
  • Cannot be applied to data already in
  • Primary keys: CONCAT()
  • Buckets: IF(), AND(), NOT()
  • Standardize: PROPER(), REPLACE()

Data transforms

  • Split records, aggregate, join sources, explode or collapse arrays
  • Batch: full refresh, scheduled or manual, DLO or DMO source
  • Streaming: one row at a time as ingested, DLO only
  • Neither replaces a Calculated Insight

Design checklist before you ingest

  • Primary keys

    Does each source have a unique identifier? Build one with a formula if not. Enforced at the data stream level.

  • Data types

    Align types between source and Data 360.

  • Time zone

    Data 360 interprets as UTC and persists datetimes in UTC. Specify time zone with the date format.

  • Contact points

    Multiple emails, phones, addresses per person? Plan whether to transpose.

  • Category

    Profile or Engagement first, Other for supporting data.

  • Cleanse

    Cleanse before ingestion where you can, transform when needed.

  • Five Vs

    Volume, velocity, veracity, variety, value. Is there a true business need? System of record or data lake?

Fully qualified keys

The problem

  • CRM Individual C-001 is Astro. eComm Individual C-001 is Appy.
  • Totals joined on the ID alone give both the same spend

The fix

  • Add a key qualifier naming the source
  • Key + qualifier is the fully qualified key
  • Astro and Appy now keep separate transactions

Zero Copy and data collaboration

  • Zero Copy federation

    Data stays in Snowflake, BigQuery or other partners, and Data 360 reads it in place. Query federation or file federation. Works both ways: bi-directional.

  • Data shares

    Share Data 360 data out to other platforms.

  • Private Connect

    Keeps Zero Copy traffic off the public internet.

Watch for these

  • Order feed with order date, shipment date, modified date and file extracted date: choose Order Date. The others change.
  • Streaming transforms act on one row at a time, so they cannot do joins and aggregates.
  • DMOs don't have their own category, so the first mapping decides it.
