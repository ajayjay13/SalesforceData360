Data Enhancements, Sharing, and Analysis

Insights, referencing Data 360 data from other systems, reports and dashboards, predictive models, and RAG for generative AI.

  • Demonstrate how to enhance data and build insights on unified data.
  • Explain how to reference Data 360 data from other systems.
  • View and build reports and dashboards using Data 360.
  • Apply predictive and generative AI tooling capabilities of Data 360 to customer scenarios.

Why enhance

  1. DMOsnapshot of state
  2. Insightactive business meaning

DMOs say a customer made five purchases. They do not say lifetime value, VIP, or twenty help-page visits in ten minutes.

Building a Calculated Insight

  1. Selectobjects, join if needed
  2. Operateaggregate, calculate, filter
  3. Definemetrics and dimensions
  4. Runonce or every 1, 6, 12, 24 h
  5. Trackreport on history

Metrics are numbers (SUM, COUNT, AVG). Dimensions give context (Unified Individual, product, region).

AI Models (formerly Einstein Studio)

  • Regression

    Predicts a number: opportunity amount, time to close, customer lifetime value, satisfaction.

  • Binary classification

    Predicts one of two outcomes: churned or not, won or lost, escalated or not.

  • On demand

    Prediction inside the flow of work through Flow, Apex, agent actions or the Predict API. Not stored unless you store it.

  • Batch

    Large data sets, written back to DLOs or ML Prediction DMOs, via batch transforms or batch predict jobs.

  • Streaming

    Near-real-time, stored in an ML Prediction DMO, can trigger Data Cloud-triggered flows when the value changes.

  • Cost

    Predictive: unique inferences. Generative: Einstein requests or Flex Credits.

RAG, step by step

  1. Connectstructured and unstructured data (DLOs, UDLOs)
  2. Map and unifyDMOs and UDMOs
  3. Search indexchunk and vectorize
  4. Retrieverindividual or ensemble
  5. Prompt templateembed the retriever

At run time the template triggers, the retriever finds relevant chunks, the augmented prompt goes to the LLM.

Search and retrievers

  • Vector search

    Text becomes embeddings that capture meaning. Best for intent and context.

  • Hybrid search

    Vector plus keyword. Keyword nails exact terms like part number XYZ123.

  • Retriever

    Wraps search operations. One retriever reads one search index. One index covers one DMO.

  • Ensemble retriever

    Runs several retrievers, merges and reranks results. Use for multiple sources.

  • Prompt template

    Reusable prompt built in Prompt Builder with goal, constraints and brand guidance.

  • Grounding

    Connect the prompt to relevant data so the answer is not generic.

  • Notebook AI

    Upload sources, ask questions, check citations, publish an authoritative article.

Watch for these

  • Enabled versus implemented: Agentforce Data Library and the Trust Layer need Data 360 enabled. Custom RAG, cleansing and rich customer data need it implemented.
  • SQL is the engine behind validation. Know the naming suffixes.
  • Calculated Insights carry cost considerations, so schedule them to match how often the use case really needs fresh numbers.
